# ユーザーマニュアル - OpenRadioFM v.4.7 Beta Server

**OpenRadioFM v.4.7 Beta Server** へようこそ。これはAndroidヘッドユニット向けのFMラジオの究極の進化形です。このバージョンでは、クラウドストリーミングとロゴ管理機能が導入され、最大限の安定性とパフォーマンスが最適化されています。

---

## 1. インターフェースとナビゲーション

### 1.1 画面レイアウト
OpenRadioFMには2つのメインデザインがあります：
- **V2 (クラシック垂直):** タブレットスタイルや垂直画面に最適化されています。
- **V3 (プレミアム水平):** ダッシュボードに最適なワイドスクリーンデザインで、大きなアイコンと**「ガラスモード」**効果が特徴です。
- **切り替え方法:** **LOC/DX** ボタンを長押しして切り替えます。アプリは自動的に再起動します。

### 1.2 お気に入りナビゲーション (ハードウェア)
- **お気に入り:** 中央のボタンで保存したステーション間をスキップします。ステアリングホイールコントロール (K706/MT8163) と互換性があります。
- **シーク:** 外側のボタンで自動信号検索を行います。

---

## 2. プレミアムカスタマイズ (シークレットメニュー)

**設定 (EQ)** ボタンを長押ししてアクセスします：

### 2.1 テーマカラーとナイトモード
10種類のカラースキームから選択できます。**ナイトモード**では、夜間の視認性を向上させ、目の疲れを軽減するために「ナイトブルー」が適用されます。

### 2.2 背景モード (ガラスモード)
1. **ピュアブラック:** 最大のコントラスト。
2. **background.png 画像:** `/sdcard/RadioLogos/background.png` からカスタム画像を読み込みます。
3. **ダイナミックロゴ (ガラスモード):** ステーションロゴから背景が自動的に生成されます。

---

## 3. オンラインロゴとストリーミング [v4.7 Betaの新機能]

### 3.1 ロゴサーバー (ベータ)
アプリはSupabaseサーバーからロゴを自動的にダウンロードできます。
- **重要:** 現在、ロゴカタログは主に**スペイン**に焦点を当てています。他の地域も順次追加される予定です。
- *プレミアム設定 > オンラインロゴ* で有効にします。

### 3.2 オンラインストリーミング (ベータ)
- **機能:** FM信号が弱い場合にインターネット経由でステーションを聴くことができます。
- **ステータス:** この機能は**テスト**段階です。現在、ストリーミングカタログは主に**スペイン**のステーションに焦点を当てています。
- **ハードウェア:** MT8163エンジンは、FMとストリーミングの切り替え時のフリーズを防ぐために最適化されています。

---

## 4. お気に入りの管理

### 4.1 保存と読み込み (.fav)
**フロッピーディスク (💾)** ボタンを使用して、お気に入りリストをエクスポートまたはインポートします。これにより、バックアップやデバイス間での設定移動が可能になります。

---

## 5. ハードウェア設定

オーディオやチューニングの問題が発生した場合は、*ハードウェア設定* でエンジンを選択してください：
- **HCN (K706):** Vento/HCNユニット用。
- **Eonon/Topway (MT8163):** v4.7でフリーズを防ぐために最適化されています。
- **QS6:** Nanis/NWDユニット用。
