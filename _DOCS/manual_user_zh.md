# 用户手册 - OpenRadioFM v.4.7 Beta Server

欢迎使用 **OpenRadioFM v.4.7 Beta Server**，这是针对 Android 车机（Head Units）的 FM 收音机的最终进化版。此版本引入了云端流媒体和徽标管理功能，并针对最大的稳定性和性能进行了优化。

---

## 1. 界面与导航

### 1.1 屏幕布局 (Layouts)
OpenRadioFM 具有两种主要设计：
- **V2 (经典垂直):** 针对平板式或垂直屏幕进行了优化。
- **V3 (高级水平):** 宽屏设计，非常适合仪表板，具有大图标和 **"Glass Mode"** 效果。
- **如何切换:** 长按 **LOC/DX** 按钮进行切换。应用程序将自动重启。

### 1.2 收藏夹导航 (硬件)
- **收藏夹:** 中间的按钮可在保存的电台之间跳转。与方向盘控制（K706/MT8163）兼容。
- **搜索 (Seek):** 外部按钮执行自动信号搜索。

---

## 2. 高级个性化 (秘密菜单)

长按 **设置 (EQ)** 按钮以访问：

### 2.1 主题颜色和夜间模式
从 10 种配色方案中进行选择。在 **夜间模式** 下，将应用“夜蓝色”以提高夜间可见度并减少眼睛疲劳。

### 2.2 背景模式 (Glass Mode)
1. **纯黑:** 最大对比度。
2. **background.png 图像:** 从 `/sdcard/RadioLogos/background.png` 加载自定义图像。
3. **动态徽标 (Glass Mode):** 背景会根据电台徽标自动生成。

---

## 3. 在线徽标与流媒体 [v4.7 Beta 新功能]

### 3.1 徽标服务器 (Beta)
应用程序可以从我们的 Supabase 服务器自动下载徽标。
- **重要提示:** 目前，徽标目录主要针对 **西班牙**。更多地区将逐步添加。
- 在 *高级设置 > 在线徽标* 中启用。

### 3.2 在线流媒体 (Beta)
- **功能:** 如果 FM 信号较弱，可以通过互联网收听电台。
- **状态:** 此功能处于 **测试** 阶段。流媒体目录目前专注于 **西班牙** 的电台。
- **硬件:** MT8163 引擎已针对在 FM 和流媒体之间切换时防止冻结进行了优化。

---

## 4. 收藏夹管理

### 4.1 保存与加载 (.fav)
使用 **软盘 (💾)** 按钮导出或导入您的收藏夹列表。这允许进行备份或在设备之间移动设置。

---

## 5. 硬件配置

如果您遇到音频或调谐问题，请在 *硬件设置* 中选择您的引擎：
- **HCN (K706):** 适用于 Vento/HCN 装置。
- **Eonon/Topway (MT8163):** 已优化以防止 v4.7 中的冻结。
- **QS6:** 适用于 Nanis/NWD 装置。

---
**注意:** 这是一个 **BETA** 版本。某些服务器和流媒体功能正在不断测试中。
