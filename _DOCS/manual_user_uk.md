# Посібник користувача - OpenRadioFM v.4.7 Beta Server

Ласкаво просимо до **OpenRadioFM v.4.7 Beta Server**, найкращої еволюції FM-радіо для автомобільних магнітол на Android. Ця версія впроваджує можливості хмарного стрімінгу та керування логотипами, оптимізовані для максимальної стабільності та продуктивності.

---

## 1. Інтерфейс та навігація

### 1.1 Макети екрана
OpenRadioFM має два основні дизайни:
- **V2 (Класичний вертикальний):** Оптимізований для екранів у стилі планшета або вертикальних екранів.
- **V3 (Преміум горизонтальний):** Широкоформатний дизайн, ідеальний для приладових панелей, з великими іконками та ефектом **"Glass Mode"**.
- **Як переключитися:** Утримуйте кнопку **LOC/DX** для перемикання. Додаток перезапуститься автоматично.

### 1.2 Навігація в обраному (Апаратне забезпечення)
- **Обране:** Центральні кнопки дозвољають перемикатися між вашими збереженими станціями. Сумісно з кнопками на кермі (K706/MT8163).
- **Пошук (Seek):** Зовнішні кнопки виконують автоматичний пошук сигналу.

---

## 2. Преміум налаштування (Секретне меню)

Утримуйте кнопку **Налаштування (EQ)**, щоб отримати доступ до:

### 2.1 Кольори теми та нічний режим
Виберіть одну з 10 кольорових схем. У **Нічному режимі** буде застосовано "Night Blue" для покращення нічної видимості та зменшення навантаження на очі.

### 2.2 Режим фону (Glass Mode)
1. **Чистий чорний:** Максимальний контраст.
2. **Зображення background.png:** Завантажте власне зображення з `/sdcard/RadioLogos/background.png`.
3. **Динамічний логотип (Glass Mode):** Фон автоматично генерується на основі логотипу станції.

---

## 3. Онлайн-логотипи та стрімінг [Нове у v4.7 Beta]

### 3.1 Сервер логотипів (Beta)
Додаток може автоматично завантажувати логотипи з нашого сервера Supabase.
- **ВАЖЛИВО:** Наразі каталог логотипів зосереджений переважно на **Іспанії**. Інші регіони будуть додаватися поступово.
- Увімкніть у *Преміум налаштуваннях > Онлайн-логотипи*.

### 3.2 Онлайн-стрімінг (Beta)
- **Функціональність:** Слухайте станції через інтернет, якщо FM-сигнал слабкий.
- **Статус:** Ця функція знаходиться на етапі **тестування**. Каталог стрімінгу наразі зосереджений на станціях **Іспанії**.
- **Апаратне забезпечення:** Движок MT8163 був оптимізований для запобігання зависанням при перемиканні між FM та стрімінгом.

---

## 4. Керування обраним

### 4.1 Збереження та завантаження (.fav)
Використовуйте кнопку **Дискета (💾)** для експорту або імпорту списку обраного. Це дозволяє створювати резервні копіји або переносити налаштування між пристроями.

---

## 5. Апаратні налаштування

Якщо у вас виникають проблеми зі звуком або налаштуванням, виберіть движок у *Hardware Settings*:
- **HCN (K706):** Для пристроїв Vento/HCN.
- **Eonon/Topway (MT8163):** Оптимізовано для запобігання зависанням у версії v4.7.
- **QS6:** Для пристроїв Nanis/NWD.
