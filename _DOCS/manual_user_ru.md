# Руководство пользователя - OpenRadioFM v.5.0.0-Beta "Stability Edition"

Добро пожаловать в **OpenRadioFM v.5.0.0** — версию, сфокусированную на максимальной стабильности оборудования и визуальном совершенстве. В этом обновлении представлен новый **Светлый режим (White Skin)** и критические исправления для процессоров MediaTek.

---

## 1. Интерфейс и навигация

### 1.1 Режимы экрана (Layouts)
OpenRadioFM поддерживает два основных дизайна:
- **V2 (Классический вертикальный):** Оптимизирован для планшетных или вертикальных дисплеев.
- **V3 (Премиум горизонтальный):** Широкоформатный дизайн, идеальный для приборной панели, с крупными значками и эффектом **"Glass Mode"**.
- **Новинка: White Skin (Светлый режим):** Тема с высокой контрастностью для дневного вождения.
- **Как сменить Layout:** Удерживайте кнопку **LOC/DX** для переключения между V2 и V3.
- **Как сменить тему:** Удерживайте кнопку **Настройки (EQ)** и выберите "Выбрать тему".

### 1.2 Навигация по избранному (Hardware)
- **Избранное:** Центральные кнопки позволяют переключаться между сохраненными станциями. Совместимо с кнопками на руле (K706/MT8163).
- **Поиск (Seek):** Внешние кнопки выполняют автоматический поиск сигнала.

---

## 2. Премиум-персонализация (Секретное меню)

Удерживайте кнопку **Настройки (EQ)** для доступа:

### 2.1 Цвета темы и ночной режим
Выберите одну из 10 цветовых схем. В **Ночном режиме** будет применен цвет "Night Blue" для улучшения видимости ночью и снижения утомляемости глаз.

### 2.2 Режим фона (Glass Mode)
1. **Чистый черный:** Максимальный контраст.
2. **Изображение background.png:** Загрузите свое изображение из `/sdcard/RadioLogos/background.png`.
3. **Динамический логотип (Glass Mode):** Фон автоматически генерируется на основе логотипа станции.

---

## 3. Онлайн-логотипы и стриминг [Новинка v4.7 Beta]

### 3.1 Система логотипов (Локальный приоритет)
Приложение ищет логотипы в следующем порядке:
1. **Локальная папка**: Ищет в `/sdcard/RadioLogos/` файлы с именем `Частота_Название.png`.
2. **Онлайн-сервер**: Если локально ничего не найдено, загружает из **Supabase** (Сообщество) или веб-серверов.
- **Сброс кэша**: Удерживайте иконку **Облака**, чтобы удалить текущий логотип и принудительно начать новую загрузку.
- **Вручную**: Вы можете добавить свои логотипы, просто скопировав их в папку `RadioLogos` с именем частоты (например, `96900.png`).

### 3.2 Онлайн-стриминг (бета)
- **Функциональность:** Позволяет слушать станцию через интернет, если сигнал FM слабый.
- **Статус:** Эта функция находится на стадии **тестирования**. Каталог стриминга в настоящее время ориентирован на станции **Испании**.
- **Оборудование:** Движок MT8163 был оптимизирован для предотвращения зависаний при переключении между FM и стримингом.

### 3.3 Вклад в сообщество (краудсорсинг)
- **Как помочь:** Включите опцию **"Внести вклад в сообщество"** в премиум-настройках.
- **Как это работает:** При настройке на станцию со стабильным RDS приложение анонимно отправит частоту и PI-код на сервер, чтобы другие пользователи в вашем регионе могли пользоваться HD-логотипами.

---

## 4. Управление избранным

### 4.1 Сохранение и загрузка (.fav)
Используйте кнопку с **дискетой (💾)** для экспорта или импорта вашего списка избранного. Это позволяет создавать резервные копии или переносить настройки между устройствами.

---

## 5. Конфигурация оборудования

Если у вас возникли проблемы со звуком или настройкой, выберите свой движок в *Настройках оборудования*:
- **HCN (K706):** Для устройств Vento/HCN.
- **MediaTek 8259 / 8667:** Новый движок с улучшенной стабильностью и защитой диапазона AM.
- **Topway / Eonon (MT8163):** Оптимизировано для предотвращения дублирования экземпляров и зависаний.
- **QS6:** Для устройств Nanis/NWD.
- **УВЕДОМЛЕНИЕ О БЕЗОПАСНОСТИ**: В движках MTK диапазон AM принудительно включен для предотвращения зависаний оборудования. Не пытайтесь его отключить.
