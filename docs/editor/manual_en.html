OpenRadioFM

Manual — Backup Studio

What this website is

This editor lets you create and modify OpenRadioFM files directly in the browser (and install it as a web app on Android).

Install on Android (PWA)

  1. Open the editor in Chrome.
  2. Menu ⋮ → Install app / Add to Home screen.
  3. You’ll get an icon in the app drawer and it will open like an app.

Tabs

  • Favorites (.fav): create/edit presets by band (FM1–FM3, AM1–AM2) and download the file.
  • Options (.ors): generate a file with menu settings (language, skin, icons, background, etc.).
  • Backup (.orzip): generate a full backup (options + presets + logos/background) in a ZIP.

Favorites (.fav)

  1. Click New Preset or edit an existing one.
  2. Fill name (max 8), band and frequency.
  3. Click Save new .fav.

Options (.ors)

  • You can load an existing `.ors` and the form will be filled.
  • The (i) icon explains each field.
  • Layout: only one can be active (normal / V3 / simple).
  • Last frequency: type 87.6 / 87,6 / 87600 / 531; it will be converted to kHz.
  • Also includes: logo provider, header car/clock, steering NEXT/PREV, scheduled night mode, status bar, HD relief, AM band, save history, and presets on the right (layout 2).

Full backup (.orzip)

  • You need a loaded/created `.fav` so the backup includes your presets.
  • Optional uploads: car logo, background, and preset logos.
  • Images are resized automatically: presets/car max 300×300, background max 1920×1080.

Using the files in OpenRadioFM

Copy the generated files into the device RadioLogos folder (the one used by the app). Then use OpenRadioFM’s import/load actions.
