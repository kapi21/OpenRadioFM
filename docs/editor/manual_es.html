OpenRadioFM

Manual — Backup Studio

Qué es esta web

Este editor te permite crear y modificar archivos para OpenRadioFM directamente desde el navegador (y también instalarlo como app web en Android).

Instalar en Android (PWA)

  1. Abre el editor en Chrome.
  2. Menú ⋮ → Instalar app / Añadir a pantalla de inicio.
  3. Aparecerá un icono en el cajón de apps y se abrirá como una app.

Pestañas

  • Favoritos (.fav): crea/edita presets por banda (FM1–FM3, AM1–AM2) y descarga el archivo.
  • Opciones (.ors): genera un archivo con ajustes del menú (idioma, skin, iconos, fondo, etc.).
  • Backup (.orzip): genera un backup completo (opciones + presets + logos/fondo) en un ZIP.

Favoritos (.fav)

  1. Pulsa Nuevo Preset o edita uno existente.
  2. Introduce nombre (máx 8), banda y frecuencia.
  3. Pulsa Guardar nuevo .fav.

Nota: en FM la frecuencia se guarda internamente en kHz (por ejemplo 87.6 → 87600).

Opciones (.ors)

  • Puedes cargar un `.ors` existente y se rellenará el formulario.
  • El icono (i) explica cada campo.
  • Layout: solo puede estar activo uno (normal / V3 / simple).
  • Última frecuencia: puedes escribir 87.6 / 87,6 / 87600 / 531; se convertirá a kHz.
  • Incluye además: proveedor de logos, cabecera coche/reloj, volante NEXT/PREV, modo noche con horario (marca la casilla para editar inicio/fin), tintado de logos en noche, barra de estado, relieve HD, guardar historial, presets a la derecha (layout 2) y flags del asistente inicial (idioma/país).

Backup completo (.orzip)

  • Necesitas tener un `.fav` cargado/creado para que el backup incluya tus presets.
  • Opcionalmente puedes subir: logo del coche, background y logos por preset.
  • Los logos se reescalan automáticamente: presets/coche máx 300×300, fondo máx 1920×1080.

Cómo usar los archivos en OpenRadioFM

Copia los archivos generados a la carpeta RadioLogos del dispositivo (la misma que usa la app). Luego usa las opciones de importar/cargar dentro de OpenRadioFM.
