# 📻 OpenRadioFM Favorites Editor

Esta es una aplicación web moderna y eficiente diseñada específicamente para gestionar archivos de favoritos (`.fav`) de la aplicación **OpenRadioFM**.

## ✨ Características Principales
*   **Visualización en 5 Columnas**: Gestión simultánea de bandas FM1, FM2, FM3, AM1 y AM2.
*   **Interfaz Premium**: Diseño nocturno optimizado con efectos neón y tipografía digital.
*   **Traducción Inteligente**: Soporte completo para **Español** e **Inglés**.
*   **Validación Técnica**: Aviso de rangos de frecuencia y limitación RDS PS de 8 caracteres.
*   **Gestión Visual**: Cards interactivas con efectos de barrido (scanlines) y colores dinámicos.

## 🚀 Cómo usar
1. Carga tu archivo `favoritos.fav`.
2. Edita, añade o elimina emisoras directamente en la rejilla.
3. Descarga el nuevo archivo generado con un solo clic.

## 🛠️ Instalación (Añadir a GitHub)
Para integrar este editor en tu web de OpenRadioFM:
1. Sube esta carpeta (`editor/`) a tu repositorio principal.
2. Accede vía `https://tu-usuario.github.io/OpenRadioFM/editor/`.
